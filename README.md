ION DRIFT: an original neon arcade survival game. You pilot mining skiff seven out of a collapsing nebula: harvest ion crystals to build the score multiplier, dash through hazards, and clear five waves, the fifth being the Warden, to win.

## Run it

```sh
node serve.ts --port 8080
# then open http://localhost:8080/index.html
```

## Build the entry dossier

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
